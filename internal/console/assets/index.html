EXECUTION POLICIES

Every task stays within bounds

The control plane coordinates task dependencies, worker capacity, and execution budgets for each workflow.

  1. Dispatch and dependencies

    Independent tasks execute in parallel. Dependent tasks become eligible after their prerequisites succeed.

  2. Token and runtime budgets

    Each attempt has a token limit and a runtime deadline. A circuit breaker stops execution when a budget is exhausted.

  3. Worker coordination

    Workers claim available tasks and renew their leases while executing. Expired claims can be recovered within the attempt limit.

  4. Inspect and cancel

    Inspect a workflow to review task states, worker assignments, attempts, and outcomes. Cancel a workflow to stop pending and running work.
