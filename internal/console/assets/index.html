DEPLOYMENT GUIDE

Connect your infrastructure

The deployment profile is a simulation. These steps describe running the API and independent workers against your own services.

  1. Provision PostgreSQL

    Use a managed database reachable by the API and workers. Require TLS and supply credentials through your secret manager.

    DATABASE_URL=postgres://…?sslmode=verify-full

  2. Initialize the task queue

    Run migrations once with a role that has schema permissions.

    forge -mode migrate

  3. Deploy the API and workers

    Use the same database, a strong API token, and a TLS ingress. Start each worker with a unique identity.

    forge -mode api -addr 0.0.0.0:8080
forge -mode worker -concurrency 256

  4. Connect observability

    Scrape each process and optionally supply an OTLP/HTTP collector. Verify delivery before treating it as connected.

    FORGE_METRICS_ADDR=0.0.0.0:9091
OTEL_EXPORTER_OTLP_ENDPOINT=https://collector.example
